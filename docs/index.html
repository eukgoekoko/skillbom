Know what your AI agent skills are licensed under.

skillbom scans the skills and plugins installed for Claude Code and Codex, works out each one's license, and gives you a Skill BOM (a bill of materials: every skill and plugin, where it came from and what it's licensed under) and an audit report you can hand to legal. It runs on your machine and uploads nothing.

Skills travel without their licenses

A skill is installed by copying one folder. Its license usually sits at the root of the repository it came from, so the installed copy says nothing about what you may do with it.

How it works

One command per machine. Merge the results for the whole team.

Scan

Finds user, project, managed and synced skills, installed plugins and their nested skills, for Claude Code and Codex. Each distinct version is fingerprinted by content hash.

Detect

Reads license files, plugin manifests, SKILL.md frontmatter and LICENSE texts, including source-available licenses. Every conclusion keeps its evidence and a confidence score.

Report

Writes a Skill BOM (JSON) and a self-contained HTML audit report with findings and fixes. skillbom merge combines scans from many machines into one.

An audit report legal can read

Findings grouped by rule with a fix for each, the license mix, and a filterable inventory with the evidence behind every license. It prints cleanly to PDF.

An open license file for skills

A skill-license.yaml next to SKILL.md declares the license in a form tools can check.

  • Standard SPDX expressions, plus commercial offers as LicenseRef- terms.
  • Machine-readable grants: commercial use, modification, redistribution, bundling into plugins, hosted use.
  • A content hash, so modified copies are detectable.
  • Includes, for checking license compatibility when plugins bundle other people's skills.
Read the spec 
# skill-license.yaml
specVersion: "0.1"
subject:
  kind: skill
  id: lexicon/contract-check
  version: 2.1.0
license:
  expression: CC-BY-NC-4.0 OR LicenseRef-team
  offers:
    - id: LicenseRef-team
      scope: { licensee: team, seats: 10 }
      term: { type: subscription, durationDays: 365 }
      grants:
        commercialUse: true
        modify: true
        compose: internal-only
